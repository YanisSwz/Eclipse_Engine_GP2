# <img src="./Images/EngineLogo.png" width="35" height="35"> Eclipse Engine

The goal of this project is to create a game engine and a game editor.

## 📝 Informations

We are 3 and have 3 months to create a game engine and its editor, using external libraries and our own code.

This project is made using c++ 20 and Visual Studio 2022.

## 📖​ Libraries

### 💻​ Rendering
- [ImGUI](https://github.com/ocornut/imgui)
- [GLFW](https://www.glfw.org/)
- [GLEW](https://glew.sourceforge.net/)
